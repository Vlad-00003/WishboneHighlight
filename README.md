# WishboneHighlight
This mod adds visual to the wishbone, showing the exact position of the found object, it's name (if known) and distance to it

## Settings
### General
Enabled - determines if the mod is enabled at all
### Arrow
Always Visible - If enabled hud arrow would always be on the screen. If not - only if the world marker is not on the screen
Color - Color of the arrow
Size - Size of the arrow
### World Marker
Size - size of the marker
Color - color of the marker

---
Tested on the latest version of the game at the moment - 1.0.17, works for deep north chests as well.
Due to the way mod is made it would probably work if any new beacons for wishbone would be added to the game.
